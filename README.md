# Logic Gates Learning Lab

A simple, interactive browser-based app to understand logic gates in a way that actually sticks.

No installations. No frameworks. Just open and learn.

---

## What this app teaches

* AND, OR, NOT gates with intuitive explanations
* NAND in detail (including why it can build everything)
* NOR, XOR, XNOR with clear memory hooks
* Interactive playground to test inputs in real time
* Truth tables generated dynamically
* Binary addition preview (SUM and CARRY using XOR and AND)
* Quiz to reinforce learning

---

## Why this exists

Most explanations of logic gates are either:

* Too theoretical
* Or too superficial

This app focuses on:

* Simple mental models
* Real-life analogies
* Interactive understanding

The goal is:

> You should be able to reconstruct everything from memory after using this once.

## How to use

1. Download or clone the repository
2. Open the file:

```
logic_gates_teaching_app.html
```

3. That’s it. It runs locally in your browser

Works on:

* Chrome
* Safari
* Edge
* Mobile browsers

## Key memory hooks

* AND → all
* OR → any
* NOT → opposite
* NAND → not all
* NOR → none
* XOR → different
* XNOR → same
