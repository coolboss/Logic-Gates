1. The whole idea in one sentence

A logic gate is a tiny rule machine. It receives 0s and 1s and gives one output: either 0 or 1.

0 means OFF / NO / FALSE. 1 means ON / YES / TRUE.
Bit

One small unit of information. It can only be 0 or 1.

Gate

A rule applied to bits. Example: both must be true.

Circuit

Many gates connected together. This becomes arithmetic, memory and the CPU.

2. AND and OR

These two are the first gates to master.

AND gate

Memory hook: AND is strict. Both inputs must be 1.

OR gate

Memory hook: OR is generous. Any one input is enough.

3. NOT gate

NOT is the simplest gate. It flips the input.

Memory hook: NOT means opposite.

4. NAND in detail

NAND means NOT AND. First do AND. Then reverse the answer.

NAND says: everything is 1 except the perfect AND case.

Truth table

Why NAND is special

You can build NOT, AND and OR using only NAND. That means NAND alone can build an entire computer.

NOT A = A NAND A
AND = NOT(A NAND B)
OR = (NOT A) NAND (NOT B)

Build other gates from NAND

NOT from NAND

Feed the same input into both NAND inputs.

A NAND A = NOT A

AND from NAND

NAND gives the opposite of AND. Reverse it again.

A AND B = (A NAND B) NAND (A NAND B)

OR from NAND

Invert both inputs first. Then NAND them.

A OR B = (A NAND A) NAND (B NAND B)

5. Are NOR, XOR and XNOR required?

You do not need to master all of them at the beginning, but you should recognize them.

NOR

NOR means NOT OR. Output is 1 only when both inputs are 0.

Memory hook: NOR is extremely strict about silence.

XOR

XOR asks: are the two inputs different?

Memory hook: XOR means either one, but not both.

XNOR

XNOR asks: are the two inputs same?

Memory hook: XNOR means agreement detector.

7. Preview: how gates create addition and carry

This is where logic gates start looking like a real computer.

Half adder

To add two bits A and B:

SUM = A XOR B
CARRY = A AND B

Why? If both are 1, the sum position becomes 0 and carry becomes 1.
